# Gorra Kratistos

Ficha técnica de una gorra roja A-frame con bordado en japonés. Incluye:

- Frente: 最強の者へ · アレクサンドロス · マケドニア y una corona.
- Costado izquierdo: un busto griego de Alejandro Magno con el sello 大王.
- Costado derecho: Musashi, con el ensō, dos katanas, 独行道 y el sello 武蔵.
- Espalda: una corona real con la frase 我が辞書に不可能はない.
- Bajo la visera: 為せば成る.

La página contiene los mockups, los planos a escala en milímetros, los materiales, la paleta, el prompt maestro y el texto de la etiqueta.

Los mockups se generaron con Google Flow (Nano Banana 2.1).
